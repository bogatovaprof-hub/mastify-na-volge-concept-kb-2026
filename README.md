# В гостях у пиренейских мастифов

Вариант от 27 октября 2026 года по концепции заказчика и реальным фотографиям. Название сайта: «В гостях у пиренейских мастифов». Fromaragon упоминается только как прежний сайт о породе и питомнике. Публикация на GitHub Pages разрешена заказчиком.

Основная аудитория — семьи, пары и небольшие компании, которым интересны собаки и загородная жизнь. Для будущих владельцев предусмотрен личный формат с заводчиком.

Использована палитра концепции: молочный `#F6F1E7`, беж `#E4D8C3`, охра `#C89A5B`, терракота `#B45A3C`, хвойный `#2F4A3C`, графит `#2B2B2B`, сине-серый `#22303C`.

Все цены указаны за человека. Место — село Безводное. Прогулка с Екатериной, ужин, баня и ночёвка подтверждены заказчиком.

## Просмотр

В папке проекта выполнить `node preview.mjs`, затем открыть http://127.0.0.1:4177/ . Сервер слушает только локальный адрес. Остановка: Ctrl+C. Зависимости не нужны. Можно также открыть `dist/index.html` напрямую в браузере.

## Контакты и форма

Телефон и Telegram оставлены заглушками по указанию заказчика. Форма только составляет текст обращения на устройстве. Данные не отправляются, не сохраняются в хранилище браузера; бронирование не выполняется. Копирование происходит только по нажатию кнопки.

## Фотографии

В `dist/assets` добавлены неизменённые копии шести предоставленных JPEG. Исходные фотографии и DOCX вне репозитория не изменены. Старые иллюстративные WebP сохранены, новая страница на них не ссылается.

В `.openai/hosting.json` и `.github/workflows/pages.yml` изменений нет. Workflow публикует `dist` при push в `main`; публикация запускается после отправки согласованного варианта в `main`. Публикация этого варианта согласована 27 октября 2026 года. Рабочий адрес: https://bogatovaprof-hub.github.io/mastify-na-volge-concept-kb-2026/ .

## Проверка варианта

Проверены экраны 1440, 768, 390 и 320 пикселей, локальные ссылки и загрузка всех шести фотографий, выбор программы, мобильное меню и Escape, подготовка обращения и сброс устаревшего текста. Ошибок в консоли браузера при smoke-проверке не было. Данные формы не порождают сетевых запросов и не записываются в localStorage/sessionStorage. Белый текст на терракотовых кнопках используется для читаемости. Проведены проверки синтаксиса JavaScript и git diff --check.
